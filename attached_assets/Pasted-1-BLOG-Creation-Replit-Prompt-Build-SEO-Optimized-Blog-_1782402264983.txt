Deliverable 3: City-Specific Content Clusters (Ranking Power)
Build a hub-and-spoke topical cluster architecture for each target city:
Structure
Pillar page (broad topic, e.g., "Golf Carts in [City], [State]: The Complete Buyer's & Owner's Guide").
Cluster posts (3–6 per city) covering specific intents: pricing, street-legal regulations, financing, maintenance, models, communities/neighborhoods, seasonal considerations, local events, dealer comparisons.
Bidirectional internal linking: pillar links to every cluster post; every cluster post links back to its pillar and laterally to 2–3 sibling posts.
Consistent URL pattern: /blog/[city-slug]-[topic-slug] (or /blog/city/[city]/[topic] if the stack supports nested routing — pick one and stay consistent).
Per-Post GEO Targeting
Primary keyword + city/region modifier in: title, H1, first 100 words, at least one H2, meta description, slug, image alt, and OG tags.
Natural inclusion of neighborhood names, nearby landmarks, ZIP codes, and regional terminology where authentic.
LocalBusiness or Place schema reference where contextually appropriate.
Avoid keyword stuffing — content must read naturally for humans first.
Semantic SEO
Use semantically related terms, not just exact-match repetition (e.g., "electric golf cart," "low-speed vehicle," "LSV," "neighborhood electric vehicle," "street-legal cart," "lifted cart," "lithium upgrade").
Cover entity relationships (brands, models, regulations, use cases).
Answer common questions explicitly with question-formatted H2s/H3s for AI Overview / featured snippet eligibility.
